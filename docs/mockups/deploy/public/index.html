仕組み

お客様がやること、店舗がやること、自動で動くことの切り分けです。

お客様

0. 申込フォーム

Webフォームから希望日時・プラン・連絡先を送る。送信した瞬間に管理画面の一覧へ「仮予約」として入る。

  • このページの「申込フォーム」がそれ
  • 受付番号を発行し、受付メールを自動送信
店舗

1. 仮予約の確認

一覧で新着を確認。電話・来店分は「新規予約」から入力。見積は自動計算。

自動

2. 日程フィックス → カレンダー登録

「日程を確定」を押した瞬間に Google カレンダーへ予定が作られる。変更・取消も同期。

  • 件名：【貸切】利用者名・人数
  • 説明：プラン・連絡先・備考
自動

3. 利用内容の共有

確定内容を利用者にメールで送る。スタッフにはカレンダーの説明欄で共有される。

店舗

4. 当日終了 → 実績入力

実際の人数・終了時刻・追加分を入れる。確定額が再計算される。

店舗 → 自動

5. 請求先確認 → 請求書送信

宛名とメールアドレスを確認して「送信」。請求書 PDF が作られ、利用者のメールアドレスに自動送信される。

  • 請求書番号を自動採番
  • 支払期限：発行日の翌月末
店舗

6. 入金確認

入金を確認したら完了。未入金は一覧で目立たせる。

本番でつなぐもの

申込フォーム
bokashi.ink の Rental ページに置く。送信内容が管理画面の仮予約になり、お客様に受付メール、店舗に通知が飛ぶ。
データ
このモックは共有データベースに保存（同じリンクを開く人全員で共有）。本番は Firestore など店舗の DB にして、舜さん・スタッフ・コンサルが同じ一覧を見る。
カレンダー
Google Calendar API。店舗のカレンダーにサービスアカウントで書き込む。このモックでは「Googleカレンダーで開く」リンクで代用。
メール送信
Gmail API または SendGrid。差出人は店舗アドレス、請求書 PDF を添付。このモックでは送信内容を画面に表示。
請求書
テンプレートから PDF 生成。発行者情報・登録番号・振込先は設定画面で一度だけ登録。
