使い方

お客様がやること、店舗がやること、このツールが用意することの切り分けです。

初めて使うとき 最初に一度だけ

  1. 1「設定」で店舗名・発行者名・登録番号・振込先を入れる請求書に印字されます。発行者名と振込先は必須です
  2. 2「設定」でサンプルデータを消す上部の「サンプルデータ表示中」が消えれば完了
  3. 3お客様用フォームのURLをホームページや案内に載せるこのツールとは別の画面として開けます
お客様

0. 申込フォーム

Webフォームに希望日時・プラン・連絡先を入力して送信すると、申込が共有データベースに保存され、予約一覧に「Web申込」の仮予約として自動で載る。お客様の画面には受付番号が出る。

  • 受付番号（RQ-…）を自動で付ける
  • 通知は届かないので、朝と夕方に予約一覧の「仮予約」を確認する
  • 保存できなかったときだけ、メール（取込コード付き）か電話での申込を案内する
店舗

1. 仮予約にする

Web申込は一覧の「仮予約」に入っているので、内容を確認して日程調整へ進む。電話・来店分は「予約を登録」で直接入力。見積は自動計算。

店舗

2. 日程を確定する

空きとお食事の内容をお客様に返信して決める。「日程を確定」を押すと Googleカレンダーの登録画面が内容入りで開くので、保存する。

  • 件名：【貸切】利用者名・人数
  • 説明：内容・プラン・連絡先・備考
店舗

3. 確認メールを送る

「メールアプリを開いて送る」を押すと、宛先・件名・本文が入った状態でメールアプリが開く。内容を見て送信する。

店舗

4. 当日終了 → 実績入力

実際の人数・終了時刻・追加分を入れる。確定額が再計算される。

店舗

5. 請求書を発行して送る

宛名とメールアドレスを確認して「請求書を発行」。「印刷／PDF保存」で PDF を保存し、「メールを作成」で開いたメールに PDF を手で添付して送る。

  • 請求書番号は自動採番
  • 支払期限：発行日の翌月末
店舗

6. 入金確認

入金を確認したら「入金を確認した」を押して完了。期限を過ぎた未入金は作業シートで警告する。

データの保存場所と注意

保存先
共有データベース（bokashi OPSアプリと同じ Firebase）に保存され、ログインしたスタッフの端末すべてで同じ一覧が見えます。お客様の申込もここに入ります。
ログイン
管理画面はスタッフ用パスワードが必要です（一度入れると、その端末では次回から不要）。お客様用フォームにログインは要りません。ログアウトは「設定」から。
バックアップ
「設定」からJSONファイルで保存できます。月1回を目安に保存しておくと、誤って削除したときに「復元」で戻せます。
設定
請求書の発行者名・登録番号・振込先と、店舗のメールアドレスを「設定」で入れておきます（共有データベースに保存され、全端末で共通）。空欄のままだと請求書に赤字で表示されます。
今後
メール送信・カレンダー登録の完全自動化と、請求書PDFの自動添付は次の段階で対応します（管理者向け：設計書）。

設定

請求書に印字する発行者情報と、店舗の連絡先。共有データベースに保存され、スタッフ全員で共通です。

店舗・発行者情報 請求書と確認メールに使います

確認メール・請求書メールの署名に入ります。

ログイン

ログアウトすると、この端末で次に開くときにパスワードが必要になります。

データ

復元は同じIDの予約を上書きし、それ以外は追加します。

サンプルデータ

初期表示のサンプル予約です。運用を始める前に消してください。

予約データの削除

保存されている予約をすべて消します（共有データベースの場合は全端末から消えます）。元に戻せないので、先にバックアップを保存してください。
